Kestrel

Lightweight communication. Native performance.

Kestrel is an open-source desktop application project focused on providing a lightweight, modern community communication experience.

Built with Rust, Tauri 2, Svelte, and TypeScript, Kestrel aims to combine a responsive interface with efficient native desktop performance.

«Project status: Early development. Kestrel is not ready for production use. Features, architecture, and performance targets are subject to change.»

Goals

- Lightweight desktop application for Windows.
- Modern, clean, and responsive user interface.
- Low memory usage and fast startup.
- Community-oriented spaces, channels, and messaging interface.
- Local demo mode for development and testing.
- Open-source development and transparent project decisions.

Safety and integrations

Kestrel will use its own original source code, branding, and assets.

Any third-party integrations must comply with the relevant service terms, developer policies, and applicable laws.

The project will not use stolen credentials, session cookies, unauthorized account automation, private APIs, or methods designed to bypass platform restrictions.

Demo-mode content is local test data and must never be presented as real messages from an external service.
